# Huertas Fighters

Juego de lucha arcade 2D clásico en HTML5.

## Jugar

Abre [Huertas Fighters](https://lukende.github.io/huertas-fighters/) una vez activado GitHub Pages.

## Modos

- Un jugador contra la máquina.
- Dos jugadores en el mismo teclado.

## Controles

| Acción | Jugador 1 | Jugador 2 |
| --- | --- | --- |
| Movimiento | A / D | Flechas izquierda / derecha |
| Salto | W | Flecha arriba |
| Bloqueo | S | Flecha abajo |
| Puñetazo | F | K |
| Patada | G | L |

R reinicia; Escape vuelve al menú.

## Publicación

En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Versión inicial de prototipo, pendiente de pruebas de jugabilidad.
