# Kai · animaciones de trabajo vigentes

## Único recurso aprobado en esta carpeta
- `walk/kai_caminar_sutil_v4.png`: APNG real con transparencia, 8 fotogramas, 480 × 380 px cada uno.

La versión v4 procede de modificar programáticamente la v3 mediante deformaciones locales suaves. **No** procede de una lámina generada por IA y recortada.

Se han retirado de esta carpeta los antiguos ZIP de descanso, puñetazo y avance, así como sus fuentes empaquetadas, porque el usuario ha pedido conservar únicamente v4 como base de trabajo.

## Regla innegociable
NO generar una lámina/spritesheet con IA para después recortar; NO sustituir fotogramas ya aprobados con nuevas generaciones; NO generar un personaje completo al pedir correcciones locales. Modificar el recurso existente con transformaciones reproducibles, conservar alfa real y exportar únicamente APNG para las pruebas. Ver `docs/PROCESO_ANIMACIONES.md`.

Los recursos heredados en `assets/kai-real/` y `assets/kai/` pertenecen al motor anterior y siguen ahí temporalmente para evitar romper la web; **no son fuentes válidas** para animaciones nuevas. La rama `main` permanece sin cambios.
